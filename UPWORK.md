# ScopeCraft — Proposal Studio — portfolio entry

**Suggested title:** ScopeCraft — Proposal Studio — Proposal Automation & Cost Estimation

**Role:** Full-stack Python Developer

**Description:** A proposal-building portfolio application for freelancers and agencies: turn a brief and deliverables into an itemized estimate, milestones, exclusions and a reviewable document. Built a FastAPI backend and responsive JavaScript interface with browser-local saved work, versioned reviewer notes, approval status, Markdown export and JSON backup/restore. Optional Gemini summaries use a protected server-side integration. The default template workflow works without credentials and labels its output accurately.

**Skills:** Python, FastAPI, JavaScript, API Integration, Workflow Automation.

## 60–90 second demo

1. Open the live app and load the fictional example.
2. Edit one input and generate the document.
3. Inspect itemized calculations, milestones and exclusions.
4. Add a reviewer note and approve the document locally.
5. Reload to demonstrate saved work, then export Markdown or print to PDF.
6. Show the backup and restore controls; state that persistence is browser-local.

Do not claim autonomous web research, external delivery, production SaaS authentication or verified live AI output without demonstrating those features.
